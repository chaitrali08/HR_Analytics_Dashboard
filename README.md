# HR_Analytics_Dashboard
📊 HR Analytics Dashboard
An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition, workforce demographics, and key HR metrics. This project demonstrates data cleaning, data modeling, DAX calculations, and interactive dashboard design to generate meaningful business insights.

Tools Used:-
Microsoft Power BI,
Power Query,
DAX,
Excel / CSV,

Skills :-
Data Visualization
Data Analysis
Dashboard Design
Business Intelligence
